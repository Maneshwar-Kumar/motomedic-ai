# Active experiments

Create an isolated `experiments/<name>/` folder for each new comparison. Its README should state the question, fixed source/runtime, authorized run scope, compared alternatives, evidence links and exit decision. Store measurements in the matching `reports/<work-area>/<version-or-run>/` folder.

The retired full-manual Claude experiment lives in [outdated_design_choices](../outdated_design_choices/README.md) and must not be rerun without fresh owner authorization. An empty active-experiments folder is intentional; old reports do not make an experiment active.
