# Haiku fallback in the retrieved-evidence pipeline

The owner asked to use their Claude API key for Haiku 5.5 as a fallback, confirmed an approximate US$4 Anthropic balance, and identified the existing GitHub Actions secret. Implementation and validation use a conservative non-recurring US$1 ceiling. There is no deployment or GCP billing change.

Gemma remains the default provider. The prepared, disabled-by-default fallback calls `claude-haiku-5-5` only after explicit eligible availability errors (500/502/503/504 or unconfigured primary). Semantic rejection, malformed output, quota exhaustion, source/applicability/citation failures, and integrity errors never select another model. The primary transport currently combines timeout and schema errors into one code, so that ambiguous failure also stays SYSTEM_ERROR. A failed Claude attempt remains SYSTEM_ERROR. Every fallback generation reserves tokens and maximum monetary cost before transmission; uncertain reservations are retained. There is one Claude transport attempt per call, with no automatic Claude retry.

Claude receives the assembled source evidence and relevant rider history, never the whole manual. Private drafting and separate structured verification retain the three ordinary decisions, rider-resolvable clarification and verified safety precedence. The application performs final checks, saves and delivers the exact accepted buffer. Both provider policy and actual call telemetry are bound to the runtime identity. The retired full-manual Claude experiment remains archived.

The adapter uses native `output_config.format`, counts the complete request with the model-specific token-count endpoint, and validates the returned model, stop reason, content shape, usage and JSON independently. Existing application limits remain 8,192 input tokens, 1,800 output tokens and 65,536 request bytes. Thinking is explicitly disabled, supported for this model at its default effort. Token counting is an estimate, not an instantaneous billing guarantee; a maximum permitted input/output reservation bounds the estimate conservatively. Source context is never silently truncated to fit.

Official references checked 11 October 2026: [Haiku model and pricing](https://platform.claude.com/docs/en/models/haiku-5-5/overview), [structured JSON](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [complete-request token counting](https://platform.claude.com/docs/en/api/messages/count_tokens), [thinking controls](https://platform.claude.com/docs/en/build-with-claude/thinking).

The validation workflow accesses the existing `ANTHROPIC_API_KEY` secret only in its provider step. It neither prints nor transfers the secret. Its synthetic primary unavailability is explicitly distinguished from actual Anthropic calls. Hosted tests reuse the same immutable index snapshot, preserve raw results for independent source review, and do not establish deployed Firestore, Qdrant RPC or Cloud Run behavior. Current receipts belong in reports/grounded_generation/v8/.
