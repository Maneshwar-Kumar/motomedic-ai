The manual and metadata paths remain fixed for ingestion and approval verification. The source is an owner's manual; undocumented service repairs require escalation. Engineering access does not permit end-user PDF, excerpt or figure delivery. Metadata's legacy human-only review fields are historical; the exact owner-delegated v3 scope is separate and takes precedence for its approved version.

Do not add another manual without an explicit edition, checksum, applicability and permission record. A changed manual or ingestion/model configuration creates a new index version.
